Enterprise Classifieds 365 is a SharePoint Framework package for SharePoint Online and Microsoft Teams.

This package contains one client-side web part named Enterprise Classifieds 365. That web part is supported on modern SharePoint pages, as a SharePoint full-page app, and in Microsoft Teams as a channel tab and a personal app. This package does not include an application customizer, field customizer, form customizer, list view command set, or any other SharePoint Framework extension.

Employees can post items for sale, for free, for rent, for donation, or as wanted ads. They can search, save favorites, message a colleague, and review listings. Moderators can approve listings and review reports. Listing data, messages, and files stay in the customer’s SharePoint Online tenant.

A 14-day trial starts the first time the web part is used on a SharePoint site. One yearly subscription covers everyone on that site. The optional license check uses subscription.chronodat.com and does not store listing content.
